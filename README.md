# Realist

An original Godot 4 open-city prototype with third-person controls, dynamic shadows, a drivable car, and a non-graphic training pistol mechanic. It is inspired by the broad open-world city genre; it does not include GTA code, characters, or assets.

## Run

1. Install Godot 4.2 or newer.
2. Import `project.godot` in Godot and press **F6** or **F5**.

## Controls

- **WASD** — move / drive
- **Mouse** — look and aim
- **E** — enter or exit the car when nearby
- **Left mouse button** — fire the training pistol at practice targets
- **Esc** — return to the menu

## O3DS-style mode

The main menu includes an **O3DS-style mode** switch. This selects a small-window, reduced 3D render-scale preset for a handheld-like presentation. It is **not** a native Nintendo 3DS executable or a guarantee of 3DS hardware compatibility.

The city, buildings, car, and targets are procedural placeholder geometry. The repository is a playable prototype, not a 1 GB finished game; it intentionally avoids padding the download with junk data or bundling unlicensed assets.
